# UGC University community site

Free UGC creator community showcase. Edit `dist/index.html` for content and styles.

## Run

Requires Node.js 22 or newer. No package dependencies.

```sh
npm start
```

Serves on port 3000 locally; respects the host-provided `PORT` environment variable.

## Railway

Connect this repository to a Railway service and use `npm start` as the start command. Manage the custom domain in Railway networking settings.

## Community links

All five join calls to action use https://discord.gg/Z2drPPUQR as native links, with no JavaScript dependency. Update all five if the invite changes.

The page replaces the former webinar registration funnel and paid mentorship pitch. There is no registration form or countdown. The ambition to become the #1 free UGC community is framed as an ambition, not a verified ranking. Founder earnings remain identified as founder-reported experience.

GitHub, Railway, and the original ChatGPT Site do not automatically sync both ways. Pull remote changes before editing; verify the live deployment after pushing to GitHub.
