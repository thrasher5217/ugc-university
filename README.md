# UGC University webinar funnel

Tech UGC webinar landing page. Edit `dist/index.html` for content, styles, and countdown behavior.

## Run

Requires Node.js 22 or newer. No package dependencies.

```sh
npm start
```

Serves on port 3000 locally; respects the host-provided `PORT` environment variable.

## Railway

Connect this repository to a Railway service, use `npm start` as the start command, and generate a domain in the service networking settings. Add your custom domain there when ready.
